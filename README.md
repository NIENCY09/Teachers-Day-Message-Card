# Teachers' Day Message Card 🌷

A personalized *Teachers' Day Message Card* created using *HTML, CSS, and JavaScript*.

## 📌 Project Description

This project is a simple interactive web card designed to express gratitude and appreciation to teachers on Teachers' Day.

It demonstrates basic web development skills, including:

- HTML for the structure and content
- CSS for the design, layout, colors, and animations
- JavaScript for interactivity and effects

## ✨ Features

- Responsive Teachers' Day greeting card
- Personalized appreciation message
- Elegant card design
- Floating decorative elements
- Animated card entrance
- Interactive surprise button
- JavaScript confetti effect
- Mobile-friendly layout
